Linux Administration

Week 1

Which Linux distribution and version did you install?

I installed Ubuntu 26.04.1 LTS

What is Nginx, and what does it do on your server?

Nginx is an HTTP web server; for example, it serves HTML files to users.

Which commands did you use to install Nginx, check its status, and enable it to start automatically?

For installing Nginx, I used command: sudo apt install nginx.

To check its status, I used command: sudo systemctl status nginx.

Enabling it to start automatically, I used command: sudo systemctl enable nginx.service
